# Блок «Контакты»

Готовый автономный блок по предоставленному референсу. Верхнее меню и логотип сайта намеренно не включены. Люди, интерьер, стеклянная центральная панель, подиум и световые линии уже находятся в `assets/contact-background.png`; заголовки, форма, контакты, иконки, преимущества и нижняя панель сделаны кодом.

## Состав архива

- `contact-section.html` — разметка блока;
- `css/contact-section.css` — изолированные стили и адаптив;
- `js/contact-section.js` — проверка полей и отправка формы;
- `assets/contact-background.png` — второе предоставленное изображение без текста и навигации;
- `demo.html` — отдельная страница для просмотра;
- `CLAUDE_CODE_PROMPT.md` — готовое задание для Claude Code.

## Быстрый просмотр

Из папки проекта выполните:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080/demo.html`.

> При открытии `demo.html` двойным кликом браузер может запретить загрузку HTML-фрагмента. Это ограничение `file://`, а не ошибка блока; используйте локальный сервер.

## Как встроить вручную

1. Скопируйте папки `assets`, `css`, `js` в публичную часть сайта, сохранив их относительное расположение.
2. Подключите CSS в `<head>`:

   ```html
   <link rel="stylesheet" href="/путь/css/contact-section.css">
   ```

3. Вставьте содержимое `contact-section.html` вместо текущего блока контактов. Не вставляйте его внутрь `<header>`.
4. Перед закрывающим `</body>` подключите JS:

   ```html
   <script src="/путь/js/contact-section.js" defer></script>
   ```

5. Проверьте путь к фону в начале `contact-section.css`:

   ```css
   background-image: url("../assets/contact-background.png");
   ```

## Что обязательно заменить

В `contact-section.html` замените на реальные данные:

- телефон и `href="tel:..."`;
- e-mail и `href="mailto:..."`;
- Telegram-ссылку;
- адрес и ссылку на карту;
- при необходимости четыре текста преимуществ.

Исходные логотипы компаний из референса не добавлялись. Свои логотипы вставляйте внутрь `.pb-contact__trust-logos`:

```html
<div class="pb-contact__trust-logos" aria-label="Логотипы клиентов">
  <img src="/images/clients/client-1.svg" alt="Название клиента 1">
  <img src="/images/clients/client-2.svg" alt="Название клиента 2">
</div>
```

Лучше использовать монохромные SVG с прозрачным фоном. CSS сам приведёт их к серому виду, как на референсе.

## Подключение отправки формы

### Вариант 1 — HTTP endpoint

Укажите адрес обработчика в атрибуте формы:

```html
<form class="pb-contact__form" id="pb-contact-form" data-endpoint="/api/contact" novalidate>
```

JS отправляет JSON методом `POST`:

```json
{
  "name": "Имя клиента",
  "phone": "+7 999 000-00-00",
  "email": "client@example.com",
  "message": "Текст задачи"
}
```

Сервер должен вернуть любой успешный HTTP-статус `2xx`. Не помещайте секретные ключи Telegram, почты или CRM в браузерный JS — они должны находиться только на сервере.

### Вариант 2 — существующая логика сайта

Оставьте `data-endpoint` пустым и подпишитесь на событие:

```js
document.addEventListener("contact-form:submit", function (event) {
  const data = event.detail;
  // Передайте data в существующий API/CRM обработчик сайта.
});
```

## Точность и адаптивность

На ширине более 900 px композиция масштабируется пропорционально исходнику 1537×1023 и сохраняет расположение элементов. Максимальная ширина сцены — 1537 px; на более широком экране остаётся спокойный светлый фон по краям. На 900 px и меньше фото показывается целиком сверху, а элементы перестраиваются в вертикальные стеклянные карточки — иначе форма была бы слишком мелкой для ввода.

Все стили ограничены классом `.pb-contact`, поэтому не должны менять существующее меню или другие части сайта.

Для максимально близкой типографики используется шрифт `Manrope` с запасными `Inter` и `Arial`. Если `Manrope` уже подключён на сайте, дополнительное действие не требуется; иначе Claude Code может подключить его тем способом, который уже принят в проекте.
